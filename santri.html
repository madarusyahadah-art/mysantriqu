Impor Rekap Excel

Data akan ditambahkan ke riwayat tahun ajaran. Periksa pemetaan sebelum menyimpan.

Untuk menggabungkan rekap beberapa angkatan, impor file satu per satu dengan tahun awal ajaran yang sama. Data akan ditambahkan, bukan mengganti file sebelumnya. Setiap file harus memuat santri yang berbeda; santri yang sudah tercatat pada tahun ajaran ini tidak dapat diimpor ulang. Angka hari diimpor sebagai catatan aktivitas, sel kosong bukan absen, dan sheet ringkasan diabaikan.
